设置页：左侧导航里的 PICTEXT 入口

PICTEXT

pictExt 扩展的设置。改动即时生效，随时可以改回来。

帖子排序模式

「原版」= 插件完全不替换，站内本来怎么排就怎么排（默认）。「全部替换」= 首页、所有板块页、搜索页统一换成 8 项：关注 / 推荐流 / 最新 / 最多浏览 / 最多点赞 / 最多回复 / 最多收藏 / 最热。

默认排序

「全部替换」模式下进入页面时默认选中哪一项，手动切换过就以手动为准。搜索页的「推荐流」会自动换成「站内搜索」。

首页也替换

「全部替换」模式下是否连首页一起换。关掉就只在板块页 / 搜索页生效。

板块页替换

点帖子上的 #标签 进入的板块页（/forum/category/…）是否替换。8 项在任何一个板块页里都可用。

搜索页替换

搜索结果的帖子列表是否替换，关键词与板块筛选会一起带过去。

评论区排序模式

「原版」= 站内三个排序照旧，只多一个「折叠全部回复」（默认）。「改版」= 换成 最热 / 关注 / 最早 / 最新 / 最多点赞 / 最多楼高。

显示改良：三种时间

把卡片上那个「x 时间前」拆成三项：发布时间（最老的那一版）、最近更新（帖子改过才有）、最近回复（最新一条回复的时间）。

读取登录状态（仅内存）

开着才能用「关注」流和评论关注筛选：进入页面时把 Cookie 读进内存，页面关闭 / 切后台立刻清空，不写入任何存储。关掉后所有请求都是匿名只读。

楼中楼自动折叠

长贴里回复多的楼层默认折叠起来，点一下再展开；每层楼各自记住状态。

折叠阈值

楼中楼条数达到多少才默认折叠。选「1 条」就是只要有回复就折起来。

「折叠全部回复」按钮

在评论排序旁放一个按钮，一键折叠 / 展开整个帖子的楼中楼。

评论区帖子信息条

在评论区顶部补一行浏览 / 回复 / 点赞 / 发布时间 / 最后活跃 / 标签。

回复区格式工具栏

点进帖子的回复框时，自动展开站内自带的 Markdown 工具栏（和发帖页同一套：粗体、链接、代码块、公式等）。自己点「格式工具」收起后，扩展不再干预这个回复框。

卡片显示赞数

在帖子卡片上补出点赞数。

卡片显示收藏数

在帖子卡片上补出收藏数。接口没返回这个字段时不显示，也不填 0。

卡片显示标签

在帖子卡片上显示 #标签，可点进对应板块。

卡片显示置顶标记

置顶帖标题前加一枚图钉。

隐私

Cookie 只在当前页面的内存里过一手：进入页面读一次，只为判断「现在是不是登录状态」（关注流要用）；页面关闭、切到后台、路由切换都会立刻清空，不写入 localStorage / sessionStorage / IndexedDB，也不上传到任何地方，更不会改动站点本身的登录 Cookie。关掉「读取登录状态」后，所有请求回到匿名只读。这里的设置只写入本机 localStorage（键名 pictExt:settings:v1）。
